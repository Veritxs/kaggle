# Kaggle — Cinema Ticket Demand Forecasting

Predict daily ticket sales (`total_ticket`) for days 4–10 of a movie's run per
(movie, cinema) pair, given the first 3 days (D1–D3) of observed sales.

## Metric

MASE — `MAE(y_true / scale, y_pred / scale)` where
`scale = sum(D1–D3) / 3` per (movie_title, cinema_ids), clipped to a minimum of 1.

## Files

| File | Description |
|------|-------------|
| `solution.py` | Original LightGBM model. Its random-fold CV score (0.33) was misleading; it scored about 0.60 on the leaderboard. Retained only for reference. |
| `solution_v3.py` | Low-variance weekday rule. Its single holdout still skipped absent/no-show target dates, so its reported 0.374 is not leaderboard-comparable. |
| `honest_experiments.py` | Reconstructs dense, calendar-aligned D1–D10 pseudo-tests and runs expanding future-month validation. |
| `solution_v4.py` | Conservative shallow LightGBM/CatBoost ratio ensemble selected over four rolling out-of-time folds. |
| `rolling_cv_v4.csv` | Per-fold v4 MASE, row counts, movie counts, and zero/no-show rates. |
| `submission_v4.csv` | Explicit copy of the v4 candidate. |
| `submission.csv` | Current submission, generated by `solution_v4.py`. |

## Run v4

Place the seven competition CSV files next to the scripts (the raw data is not
committed), then run:

```bash
python -m pip install -r requirements.txt
python solution_v4.py
```

This writes `rolling_cv_v4.csv`, `submission_v4.csv`, and `submission.csv`.

## Reproducibility

`SEED = 2026` is fixed on every stochastic component (`np.random.seed`, all
LightGBM `random_state`, cross-validation splits).

## Key lesson

Random-fold CV was badly over-optimistic (0.33 CV → 0.60 LB). The earlier
single holdout was also incomplete because it scored only observed positive
future rows. V4 instead constructs the same dense seven-day calendar grid as
the real test, treats absent/no-show days as zero, splits by whole movie release
cohorts, and evaluates four expanding future-month folds. Model selection uses
median and worst-fold MASE rather than one favorable split.
