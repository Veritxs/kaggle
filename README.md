# Kaggle — Cinema Ticket Demand Forecasting

Predict daily ticket sales (`total_ticket`) for days 4–10 of a movie's run per
(movie, cinema) pair, given the first 3 days (D1–D3) of observed sales.

## Metric

MASE — `MAE(y_true / scale, y_pred / scale)` where
`scale = sum(D1–D3) / 3` per (movie_title, cinema_ids), clipped to a minimum of 1.

## Files

| File | Description |
|------|-------------|
| `solution.py` | LightGBM model (L1 objective, ratio target, seed-averaged). Strong on random-fold CV (0.33) but overfit the training season (LB ~0.60). |
| `solution_v3.py` | Robust rule: `scale × day-of-week factor × horizon decay`, validated **out-of-time** (latest 20% of train windows). OOT MASE ≈ 0.374 — designed to generalize across the train→test season gap. |
| `submission.csv` | Current submission (generated by `solution_v3.py`). |

## Reproducibility

`SEED = 2026` is fixed on every stochastic component (`np.random.seed`, all
LightGBM `random_state`, cross-validation splits).

## Key lesson

Random-fold CV was badly over-optimistic (0.33 CV → 0.60 LB) because it leaked
season-specific patterns. Out-of-time validation (forecasting a held-out future
slice of the train period) tracks the leaderboard far better and is the metric
used to accept changes.
