# Kaggle — Cinema Ticket Demand Forecasting

Predict daily ticket sales (`total_ticket`) for days 4–10 of a movie's run per
(movie, cinema) pair, given the first 3 days (D1–D3) of observed sales.

## Metric

MASE — `MAE(y_true / scale, y_pred / scale)` where
`scale = sum(D1–D3) / 3` per (movie_title, cinema_ids), clipped to a minimum of 1.

## Run v6

Place the seven competition CSV files next to the scripts (the raw data is not
committed), then run:

```bash
python -m pip install -r requirements.txt
python solution_v6.py
```

This writes `rolling_cv_v6.csv`, `submission_v6.csv`, and `submission.csv`.

## V6 findings

- 58% of train titles first appear as a 1-cinema preview before the wide opening;
  test D1 is the wide opening (median 70 cinemas). Aligning fixes D1, horizons,
  weekdays, and scale, and grows usable cohorts from 110 to 171 movies.
- On the aligned backtest the decay×weekday×holiday rule (LB 0.6055) scores
  0.450 and the flat baseline (LB 0.795) scores 0.728; v6 scores 0.410.

## Reproducibility

`SEED = 2026` is fixed on every stochastic component (`np.random.seed`, all
LightGBM `random_state`, cross-validation splits).

## Key lesson

Random-fold CV was badly over-optimistic (0.33 CV → 0.60 LB). The earlier
single holdout was also incomplete because it scored only observed positive
future rows. V4 instead constructs the same dense seven-day calendar grid as
the real test, treats absent/no-show days as zero, splits by whole movie release
cohorts, and evaluates expanding future-month folds. V5 selects its horizon
policy on June–August only, then uses September once as an untouched final
backtest. It improves development mean MASE from 0.67185 to 0.65648 and the
untouched September result from 0.73621 to 0.73283.
